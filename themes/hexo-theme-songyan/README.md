# 松烟 (Songyan) · Hexo 主题

> **外古内今 · 分卷而治**  
> 古意放在外壳、排版、留白与仪式感上；技术与项目保持现代阅读效率。词重仪式，技术重效率。

---

## 主题特色

1. **四卷专治：**
   - **词卷：** 词林正韵平仄检视、笺注悬停淡入联动（1.5s）、韵脚 2px 朱砂圆点标记、桌面端右起竖排横向滚动；
   - **随笔卷：** 岁月时光轴大留白、气候与驻足地元数据、防伪朱砂印章水印；
   - **技术卷：** 现代双栏效率阅读、折角纸笺札记栏（200ms 折角展开）、深色代码块一键复制；
   - **项目卷：** 结构化作品展柜、三色状态印章（维护中·竹青 / 已归档·赭石 / 实验中·黛青）、更新日志。
2. **唯一印章系统：**
   - 全站唯一一枚作者印章：「春唇语冬」2.5cm 方形元朱文（右上春、右下唇、左上语、左下冬），采用印泥红（`#B03A2E`），严禁纯红 `#FF0000`。
3. **动效纪律：**
   - 全站仅允许单一入场动词「落墨」（320ms），交互反馈 160ms，严禁超过 500ms 的过度动效。
4. **纯粹原生：**
   - 零前端框架、零外部 CDN 脚本、零 localStorage、零暗色模式切换，全站设计令牌严格来源于 `tokens.css`。

## 快速安装

```bash
cd your-hexo-site
git clone https://github.com/user/hexo-theme-songyan.git themes/songyan
```

在站点根目录 `_config.yml` 中指定主题：

```yaml
theme: songyan
```
