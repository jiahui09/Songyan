# 「松烟」(Songyan) Hexo 主题设计说明书

## 一、设计哲学：落花人独立，微雨燕双飞
- **人独立：** 每屏只有一个主角，大面积留白；条目之间以空白相隔，不画分割线。
- **落花：** 每屏至多一点暖色——词牌一点朱、词尾一瓣淡胭脂；文章不用朱红。
- **微雨：** 月白冷笺底、偏青的松烟墨，细线一律做成两端淡出的「雨丝」。
- **燕双飞：** 诗文两轨相互照应——词作出词牌与起首两句，文章出题目与摘要；题目与落款首尾相望。
- **外古内今：** 古意放在色、字、留白；技术文章保持现代阅读效率。

## 二、色板体系 (Tokens，唯一来源 `source/css/tokens.css`)
- 月白笺底 `--paper: #F3F1EC`
- 松烟墨正文 `--ink: #22282B`；雨灰元数据 `--ink-secondary` / 淡墨 `--ink-faint`（对纸 5.55:1 / 5.06:1，小字一律 ≥ 4.5:1，WCAG AA）
- 朱砂 `--cinnabar: #A8392E`：每屏至多一处
- 天青雨丝 `--celadon`、烟青悬停 `--celadon-deep`：链接、悬停、选中、导航
- 淡胭脂 `--rouge`：词尾落花一瓣
- 雨丝线 `--rain-thread`（横）/ `--rain-thread-v`（竖）
- 印泥红 `--seal-color: #B03A2E`（严禁 #FF0000 纯红）

## 三、字体
- 题字：霞鹜文楷 Lite（SIL OFL 1.1），`source/fonts/` 自托管，按 unicode-range 分片按需加载。
- 正文：系统宋体（思源宋体 / Songti / SimSun 回退链）。
- 日期一律汉字：二〇二六年十月十二日（`_partial/han-date.ejs`）。

## 四、印章系统
- 印文：春唇语冬（四字，2×2 方形元朱文），构建期由 `render_seal` 生成 SVG。
- 位置（全站仅三处）：
  - 页头小印 26px（`seal.size`）；首页唯一一次「盖下」动效
  - 文末落款 60px，压在署名右侧，略下沉如手钤
  - 404 残印 56px，opacity 0.3
- 页脚、关于页题头不落印。

## 五、版式
- 首页：**卷首大字 · 栏头题签**——仅首页第一页启用（`home.cover: false` 可关闭）。桌面 ≥900px 初始是一屏素笺（`--cover-height: 100svh`），题句与出处同组随滚动上移；题句保持原字号、字距与行距，只滑动，不缩放；出处逐渐隐去。站点页眉（站名 + 导航）同步收拢，并最终固定在画面顶部，不随正文离开。题签 sticky 只作用于停靠行程；行程结束后题签释放，与正文同层上移，不再像罩子压在内容上。底部仅淡墨箭头作下滑暗示，下滑后隐藏；不再使用「入卷」按钮。标题透明度始终为 1，不退场、不复制。窄屏为 62svh 短封面；减弱动效或不支持滚动动画时回退静态封面；打印恢复普通文流。正文始终在初始 HTML，「跳至正文」为真实锚点，无滚动劫持。
- 首页归流：整片纸面一次落墨（不再逐条错峰）；整条可点，悬停左侧浮现雨丝。
- 词作：作者在 Markdown Front Matter 用 `poetry_layout: horizontal | vertical` 选择构建结果，网页不提供切换控件。未填写或值无效时沿用 `theme.ci.vertical_desktop`，单篇设置优先；横排保留标点、不启用逐列锁页，竖排仅桌面端（≥1024px）右起排，一段一列；淡栏与竖排同断点，普通列距由 `--ci-column-pitch` 固定，在原 61px 基础上增加 12%，字列在各自列宽内水平居中。片外取消边线，仅上下片内部相邻诗句之间保留淡线，片间留白不封边，淡线墨色不透明度为 0.12（透明度 88%）、宽 1px；正文区域随最长诗句自然定高，片内淡线统一起止，头尾各内收 16px 并渐隐，不机械铺满预设列高。上下片依作者的 `stanza_break` 留出半列空白，片内以宽疏列距、长短句自然收尾形成停顿，不随机改变字号、字重或逐列位移；列内字距由 0.08em 收至 `--tracking-verse-vertical: 0.04em`，字号、字重不变。桌面竖排隐藏现代句读，形成纯汉字排版；原始内容及 DOM 中的句读保留，窄屏横排和打印恢复显示。窄屏换阕保留上下留白。不生成词注、注词跳转或着重点，也不使用悬挂小标点。题笺预览与导出沿用既有自然断句规则。桌面左侧落款与正文留 32px 间隔，作者与日期两列间隔 20px；题笺入口缩为 12px，与作者之间以及入口与落花之间各留 12px；印章尺寸、墨色不变，位于日期下方 32px，并水平居于两列之间，保持落款的从属地位。词牌朱、题目墨，词尾一瓣落花。阅读页按 `Q` 进入静读模式。
- 文章：题头居左；元信息汉字淡墨一行；引用块仅一道竖雨丝；标签以「系」字收于文末。宽屏可借 `margin_notes` 在右侧置旁批（天青雨丝引出）。
- 归档：岁时笺纸 · 大弧卷面。桌面（≥900px）横轴竖文：整条时间轴沿大半径 2D 圆弧起伏（桌面弧垂 54px，短窗按视口高度收敛至 32/20px；减弱动效时列静止平直），赭石拱轴载列，朱砂细弧与纸色描边朱点示全轴进度。年→月分组：年号分置轴上公元、轴下干支；月签列竖排「十月」与两个节气名（寒露 / 霜降），日字汉字竖排贴轴，题目竖排轴下；列距 80px，题名距轴 16px、日字距轴 12px，月组与年组各留额外呼吸。隐藏原生滚动条，滚轮阻尼、拖拽与键盘横移（Home 至最新端、End 至最旧端，保留卷首隐喻），初始停驻最新端。窄屏（&lt;900px）按窗口比例自动降级为信笺目录列表（不设手动切换）。分卷图例褪墨筛选，零匹配空态保持停靠；最近篇目 `--text-sm`。题头在停靠行程末段收缩至 `--text-dock-title`（40→28px）。
- 阅读页（词/文）：整屏题签封面——首屏只见词牌/眉题、题目、作者与日期（文可带题注），正文完全在视口外；下滑后题头以原字号上移至正文入口，正文自锚点展开；继续下滑时题目与正文等量移动。诗词定点后作者/日期完全隐去（与末尾印章重复）；文章题注随行程渐隐，元信息收为淡墨一行。桌面竖排词句在定点后随根滚动依次淡入入场。页眉同步收拢常驻。评论区（可选 Gitalk）主题化纸色墨色，并设停靠引力锚点。
- 首页归流简介：词作起首与文章摘要同用 `--text-sm`，避免抢题。
- 归档近期篇目：`--text-sm`，不抢题头。
- 内容页文末：标签、署名与题笺入口归于同一尾签区域。词作长列仅在自身区域横滚，不撑破页面。
- 关于页落款：沿用文章落款规制，作者与汉字日期分为两行并右对齐，印章在旁跨两行居中；不显示题笺入口。
- 全站页脚（含归档、分类与标签页）：统一保留雨丝、版权与说明，移除页面入口链接及对应配置；导航入口由页头承担。
- 404：一纸空笺，两处文字链接以雨丝线托底，不用按钮。

《秋夜怀远》固定为基准样例；通用性以不同体裁、字数和篇幅验证，不再用基准样例的局部像素表现代替验收。本轮只增加测试与记录，不调整主题样式。

**初轮结果：主矩阵 40 组，30 通过、10 失败；5 组无脚本与打印句读检查通过。** 当时发现以下共性问题，后续已按通用规则修复，保留原失败条件回归验证：
1. **日期反向撑高正文：** 五言绝句、五言律诗在 1024/1280/1440px，五字文本约 104px，正文被约 145.6px 的日期列撑高，片内淡线未真正按最长诗句定高。正文列高应与落款固有高度解耦。
2. **短篇印章越出可视区：** 三类短诗在三个桌面宽度共 9 组，日期下方 32px 的印章延伸到正文容器外约 92px；容器形成内部纵向滚动。应在保留正文自然留白的同时为完整落款预留可见空间。
3. **长词入场首列不可见：** 长词约 1014px 宽、可视区 880px，静态横向两端可达；正常动效从错误的水平位置开始，首列尚在区域外时已被揭示，且入场锁定阶段无法横向浏览。应按右起阅读顺序确定初始位置，并使正在揭示的列保持可见。

**修复后复验：64/64 组通过，8 组无脚本与打印句读补充检查通过；两种主题默认值下的单篇配置优先级验证通过。** 页面无排版切换入口；截图位于 `/tmp/songyan-poetry-author-modes/`，基线未覆盖。

修复方式：诗句放入独立 `.post-ci__verses`，自然列高不再被日期影响；外层为完整落款保留空间，消除内部纵向裁切。入场初始化定位右侧首列，每一步按真实可视边界移动横向滚动位置，反向退列同样保持当前列可见；末尾落款出现后解锁。无需新增依赖或逐篇专用像素值，既定字体、字重保持不变。

## 六、动效纪律
- 全站仅允许一种入场动效：「落墨」(`320ms`, `cubic-bezier(0.22, 1, 0.36, 1)`)，只动 opacity 与 6px 位移（合成层完成，不用 blur 滤镜）
- 首页归流整体一次落墨；卷首题签与页眉收拢由根滚动进度驱动（`animation-timeline: scroll(root block)`，题目仅位移、页眉独立收拢，纯 CSS，渐进增强），不做 JS 滚动插值；出处随题句缩小渐隐；页眉常驻顶部
- 归档题头停靠同法：根滚动进度驱动题头收拢、篇数与近期篇目渐隐；分类图例与离场占位为引力锚点；继续下滑时间轴整片离场；页眉常驻顶部
- 阅读页题头停靠同法：整屏题签保持字号滑至入口，再与正文同层离开；诗词 meta 隐去、文章题注渐隐；竖排列依次入场；正文与评论为引力锚点；页眉常驻顶部
- 首页、归档、阅读页仅在「停靠完成点」设 `scroll-snap-type: y proximity` + `scroll-snap-stop: always`：有阻力，克服后吸到定点，不半途卡壳；已出现的题头不会被轻滑拉回半途；减弱动效下关闭
- 首页定点时卷首出处须完全隐去（`source-fold` 在行程内结束），栏头完整保留原字号题句
- 首页页头印章「盖下」唯一动效 (`400ms`，仅一次)
- 折角纸笺展开 (`200ms`)
- 交互反馈 (`160ms`)
- 减弱动效偏好下，以上时长经 tokens 全部归零。
- 严格禁止单段 500ms 以上的拖沓动效与花哨变形；时间驱动交互统一用 `--ease-ink`，标题停靠的滚动进度映射使用 linear，不叠加惯性插值。

## 七、滚动叙事实施计划

**状态：核心实施完成，自动化复验通过；真实触屏与跨浏览器视觉复核待人工验收。** 目标为封面、题目＋正文、连续正文、全站页脚四种稳定场景互不干扰；过渡允许交接，停止后标题不得半掩、正文不得混入全站页脚。保留当前排版、诗文双轨、作者 Front Matter 与印章系统。

1. **场景几何：** 阅读页将正文、落款与评论归入完整阅读区域，短内容至少占满页眉与题签下的可用视口；全站页脚恢复自然高度，位于页面底部，不独占一屏、不居中停靠、不触发程序跳转。标题允许换行，阅读时完整显示或完整退出。
2. **统一坐标与控制：** 首页归流、阅读正文、归档工具栏分别为入口；JS 与 CSS 共用同一元素。保留原生 proximity 吸附，只有 JS 过渡和竖列锁页期间临时暂停。既有控制器只处理封面与入口，正文到页脚交由原生滚动，不新增末尾控制器。
3. **输入优先级：** 题笺与代码块等内部滚动优先；归档横轴、诗词逐列入场占用时不触发场景跳转。一次手势的余势在当前锚点消散，下一次手势才推进。支持反向、键盘、拖动与触屏释放后落定；锚点、历史返回与浏览器查找不能被拉走。
4. **重排与降级：** 字体、图片、评论、归档模式和视口变化后重算真实坐标；定点保场景，正文保进度。减弱动态、无 JS、低矮窗口、长标题不适配时保持可读的普通文流，不锁死或裁切内容。
5. **验证交付：** 在 `tests/` 建立隔离真实 Hexo 场景矩阵，覆盖短诗、长词、横排、长文章、长标题、关于、首页、归档；记录封面/入口/中段/末尾/页脚以及反向返回的几何、输入和截图。既有诗词矩阵与独立构建变体同步回归；不覆盖现有基线。

验收门槛：正文定点页脚顶端不进入视口；标题定点完整位于页眉下；页脚在文档底部完整可达，停止后不回弹；末段、落款、评论和页脚完整可达；无页面横向溢出；逐列阅读完成后释放；原文、字号与作者排版选择不改变。常规桌面采用完整叙事，窄屏与减弱动态保留原生连续阅读与阅读区/页脚分离。

实施结果：
- 阅读页、关于页和普通分页增加 `.reading-scene`，将正文、落款、评论纳入完整阅读场景；短篇不再以不相关的行程比例撑高。阅读题签在入口完整停靠，行程结束后与正文等量上移，自然离开视口，不突然隐藏；超长标题与极矮窗口恢复文流。
- 页脚维持自然高度与原有底部留白，移除整屏高度、垂直居中、正文末尾与页脚吸附以及末尾 JS 跳转。保留封面顶部锚点防止首次加载偏移；阅读结束后使用原生滚动抵达底部。
- 归档入口统一为 `.archive-toolbar`，时间轴高度扣除完整工具栏占位。
- 封面题簇、阅读题簇、归档题簇与页眉取消祖先容器的 transform 位移，改为 top 布局位置动画；首页题句按字号连续缩至 `--text-dock-title`，归档题头在行程末段收缩至同一字号，阅读与关于题目保持真实字号、字距和行距。首页、阅读、关于/分页与归档在正文入口后均由封面容器边界释放题目，使题目与正文等量移动；页眉自身的收拢规则独立保留，避免合成层缩放和题目正文割裂。

### 封面至正文的连续状态
1. **初见：** 题句与出处周围保留连续净纸区；笔墨偏置于下部或一侧，少量浓墨树石建立真实质地，水面和云气与纸面空域连通。
2. **下滑：** 题句上移收为题签；取景沿山势小幅展开，以自然轮廓显露岸线或水域，引导视线向正文。只采用一次构图展开、一次阅读交接，适配现有停靠节奏。
3. **正文到达：** 同一画面的岸线、山势或烟岚跨越封面末端与正文入口，保留可辨认的空间线索；浓墨避开字区，画中空域承接首批篇目或首段。
4. **深入阅读：** 残山随纸面离开，正文保持清晰；不设全站固定画层，也不在全文各节重复播放。
5. **向上返回：** 按同一滚动进度复原构图，不重新触发独立入场动画。
- 封面与正文入口共用纸色、纸纹尺度及纹理坐标；版心、空白和行气连续，不在入口突然切换为另一块表面。
- 首页进入文章仍是正常页面导航；通过笔墨、纸面与排版语言延续，不承诺跨页面无缝变形。

### 笔墨融合与交互纪律
- 先处理素材：保留皴擦、渗化、飞白和干湿层次，校正扫描底色，清理装裱边与无关纸框；不得将整画均匀淡化为灰雾。
- 沿云、水、山脚的自然空域制作透明边缘或蒙版，避免矩形图框、等宽羽化和整齐扫屏。
- 画层与标题独立计算几何；标题收拢时山石不压扁，不把亭、舟、树拆成独立漂浮物，也不伪造逐笔作画。
- 可在隔离画层内验证正片叠底；标题、导航、日期与出处保持正常渲染和净纸背景，不参与画层混色。
- 变化绑定实际滚动位置，停止滚动即停止变化；优先复用 CSS 滚动时间轴，不增加云雾循环、鼠标视差或第二套滚动控制器。
- 手机重新取景，不简单居中裁切桌面图；减弱动态效果或不支持滚动时间轴时呈现完整静态构图，阅读和来源说明仍可访问。
