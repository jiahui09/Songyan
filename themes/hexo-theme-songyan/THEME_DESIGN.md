# 「松烟」(Songyan) Hexo 主题设计说明书

## 一、设计哲学：落花人独立，微雨燕双飞
- **人独立：** 每屏只有一个主角，大面积留白；条目之间以空白相隔，不画分割线。
- **落花：** 每屏至多一点暖色——词牌一点朱、词尾一瓣淡胭脂；文章不用朱红。
- **微雨：** 月白冷笺底、偏青的松烟墨，细线一律做成两端淡出的「雨丝」。
- **燕双飞：** 诗文两轨相互照应——词作出词牌与起首两句，文章出题目与摘要；题目与落款首尾相望。
- **外古内今：** 古意放在色、字、留白；技术文章保持现代阅读效率。

## 二、色板体系 (Tokens，唯一来源 `source/css/tokens.css`)
- 月白笺底 `--paper: #F3F1EC`
- 松烟墨正文 `--ink: #22282B`；雨灰元数据 `--ink-secondary` / 淡墨 `--ink-faint`（对纸 5.55:1 / 5.06:1，小字一律 ≥ 4.5:1，WCAG AA）
- 朱砂 `--cinnabar: #A8392E`：每屏至多一处
- 天青雨丝 `--celadon`、烟青悬停 `--celadon-deep`：链接、悬停、选中、导航
- 淡胭脂 `--rouge`：词尾落花一瓣、难词着重点
- 雨丝线 `--rain-thread`（横）/ `--rain-thread-v`（竖）
- 印泥红 `--seal-color: #B03A2E`（严禁 #FF0000 纯红）

## 三、字体
- 题字：霞鹜文楷 Lite（SIL OFL 1.1），`source/fonts/` 自托管，按 unicode-range 分片按需加载。
- 正文：系统宋体（思源宋体 / Songti / SimSun 回退链）。
- 日期一律汉字：二〇二六年十月十二日（`_partial/han-date.ejs`）。

## 四、印章系统
- 印文：春唇语冬（四字，2×2 方形元朱文），构建期由 `render_seal` 生成 SVG。
- 位置（全站仅三处）：
  - 页头小印 26px（`seal.size`）；首页唯一一次「盖下」动效
  - 文末落款 60px，压在署名右侧，略下沉如手钤
  - 404 残印 56px，opacity 0.3
- 页脚、关于页题头不落印。

## 五、版式
- 首页：**卷首大字 · 栏头题签**——仅首页第一页启用（`home.cover: false` 可关闭）。桌面 ≥900px 初始是一屏素笺（`--cover-height: 100svh`），题句与出处同组随滚动上移；题句字号收到 50%，出处同步缩小并逐渐隐去。站点页眉（站名 + 导航）同步收拢，并最终固定在画面顶部，不随正文离开。题签 sticky 只作用于停靠行程；行程结束后题签释放，与正文同层上移，不再像罩子压在内容上。底部仅淡墨箭头作下滑暗示，下滑后隐藏；不再使用「入卷」按钮。标题透明度始终为 1，不退场、不复制。窄屏为 62svh 短封面；减弱动效或不支持滚动动画时回退静态封面；打印恢复普通文流。正文始终在初始 HTML，「跳至正文」为真实锚点，无滚动劫持。
- 首页归流：整片纸面一次落墨（不再逐条错峰）；整条可点，悬停左侧浮现雨丝。
- 词作：桌面端（≥1024px）右起竖排，一句一列，过片空一段；窄屏横排。词牌朱、题目墨，词尾一瓣落花，笺注小字列于其后，难词点按跳转。
- 文章：题头居左；元信息汉字淡墨一行；引用块仅一道竖雨丝；标签以「系」字收于文末。
- 归档：岁时笺纸横轴，月日采用两位数字分层（MM / DD），整组斜置 −30°，年份仍为汉字；西文按词侧排而非逐字母堆叠。取消三维透视，长题可折列。细滚动条与进度墨点提示方向，滚轮到端点交还页面；筛选同步计数、零篇显示空态。轴线天青、雨灰。桌面首屏为题头 + 近期篇目（互不重叠）；下滑后近期隐去，题头收拢到页眉下，分类图例与时间轴在剩余一屏内完整展示（轴上下高度随定点压缩）；页眉同步收拢并常驻顶部。轴上墨点与年界节点叠于轴线之上。
- 内容页文末：标签、署名与题笺入口归于同一尾签区域；笺注以淡雨丝分隔，注词与释义分栏。词作长列仅在自身区域横滚，不撑破页面。
- 404：一纸空笺，两处文字链接以雨丝线托底，不用按钮。

## 六、动效纪律
- 全站仅允许一种入场动效：「落墨」(`320ms`, `cubic-bezier(0.22, 1, 0.36, 1)`)，只动 opacity 与 6px 位移（合成层完成，不用 blur 滤镜）
- 首页归流整体一次落墨；卷首题签与页眉收拢由根滚动进度驱动（`animation-timeline: scroll(root block)`，字号与位移，纯 CSS，渐进增强），不做 JS 滚动插值；出处随题句缩小渐隐；页眉常驻顶部
- 归档题头停靠同法：根滚动进度驱动题头收拢、篇数与近期篇目渐隐；分类图例随时间轴进入焦点区；页眉常驻顶部
- 首页与归档仅在「停靠完成点」设 `scroll-snap-type: y proximity` + `scroll-snap-stop: always`：要么停在卷首/首屏，要么吸到定点；已出现的题头不会被轻滑拉回半途；减弱动效下关闭
- 首页定点时卷首出处须完全隐去（`source-fold` 在行程内结束），栏头只留缩小题句
- 首页页头印章「盖下」唯一动效 (`400ms`，仅一次)
- 折角纸笺展开 (`200ms`)
- 交互反馈 (`160ms`)
- 减弱动效偏好下，以上时长经 tokens 全部归零。
- 严格禁止单段 500ms 以上的拖沓动效与花哨变形；时间驱动交互统一用 `--ease-ink`，标题停靠的滚动进度映射使用 linear，不叠加惯性插值。
