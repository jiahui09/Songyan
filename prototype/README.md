## 动效纪律（全站遵守）

全站只允许一种入场动效——**「落墨」**：

```css
@keyframes luo-mo {
  from { opacity: 0; filter: blur(2px); transform: translateY(4px); }
  to   { opacity: 1; filter: blur(0);   transform: translateY(0); }
}
.enter {
  animation: luo-mo var(--dur-enter) var(--ease-ink) both;
}
```

- **时长铁律：**
  - 入场：`320ms`（`--dur-enter`）
  - 交互反馈：`160ms`（`--dur-feedback`）
  - 折角展开：`200ms`（`--dur-unfold`）
  - 印章盖下：`400ms`（`--dur-seal`，仅在首页卷首出现一次，不重复）
  - **严禁全站出现任何 500ms 以上的动效！**
- **作用范围：** 首页各分卷卡片、文章正文一级标题、归档页时间轴节点。
- **无障碍保障：** 严格遵循 `prefers-reduced-motion: reduce`，开启时所有动效瞬间静止。

## 契约标记使用说明

为使本地 Agent 能够无损、机械化地将静态原型转换为 Hexo EJS 模板，所有动态字段与循环均已用规范注释标记：

1. **动态变量：** `<!-- @hexo: page.title --> ... <!-- @end -->`
2. **循环遍历：** `<!-- @hexo: for post in site.posts --> ... <!-- @end -->`
3. **条件判断：** `<!-- @hexo: if page.tags && page.tags.length --> ... <!-- @end -->`
4. **资源路径：** 所有静态资源均采用相对路径，并在行尾标注 `<!-- 待转 url_for(...) -->`。

详见随附契约文档：
- `COMPONENT_MAP.md`：HTML 区块与 Hexo Partial 映射表
- `DATA_SHAPE.md`：所有动态数据字段定义与缺失兜底策略
- `KNOWN_LIMITS.md`：已知设计边界与 v0.1 实现限制
